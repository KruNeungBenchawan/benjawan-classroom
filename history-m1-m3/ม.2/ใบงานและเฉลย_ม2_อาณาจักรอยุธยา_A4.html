📄 ใบงานประวัติศาสตร์ ม.2 (พว.) — อาณาจักรอยุธยา (รวม 2 ใบงาน) 🔑 โหมดครูผู้สอน (แสดงเฉลย)

ใบงานที่ ๒.๑ เรื่อง การสถาปนาและพัฒนาการด้านการเมือง-เศรษฐกิจ-สังคมสมัยอยุธยา

วิชาประวัติศาสตร์ ม.๒ (พว.) ฉบับเฉลยครู
ชื่อ-นามสกุล: ............................................................................................ ชั้น: ม.๒ / ......... เลขที่: ......... คะแนนที่ได้: ........ / ๒๐ คะแนน
ตอนที่ ๑ : เติมข้อมูลเกี่ยวกับการสถาปนาและปัจจัยความเจริญของกรุงศรีอยุธยา (๕ คะแนน)
๑. ผู้สถาปนากรุงศรีอยุธยาเมื่อ พ.ศ. ๑๘๙๓ คือ สมเด็จพระรามาธิบดีที่ ๑ (พระเจ้าอู่ทอง) โดยเป็นการรวมอำนาจของ ๒ แคว้นสำคัญคือ แคว้น ละโว้ (ลพบุรี) และแคว้น สุพรรณภูมิ (สุพรรณบุรี)
๒. เกาะเมืองอยุธยามีแม่น้ำล้อมรอบ ๓ สาย ได้แก่ แม่น้ำเจ้าพระยา, แม่น้ำป่าสัก และแม่น้ำลพบุรี
๓. ตลอดเวลา ๔๑๗ ปี อยุธยามีราชวงศ์ปกครองรวม ๕ ราชวงศ์ โดยราชวงศ์ที่ครองราชย์ยาวนานที่สุด (๑๓ พระองค์) คือ ราชวงศ์สุพรรณภูมิ
ตอนที่ ๒ : ตารางเปรียบเทียบการจัดระเบียบการปกครองสมัยอยุธยา ๓ ยุค (๙ คะแนน)
ยุคสมัย การปกครองส่วนกลาง (ราชธานี) การปกครองส่วนภูมิภาค (หัวเมือง)
๑. อยุธยาตอนต้น
(พ.ศ. ๑๘๙๓ – ๑๙๙๑)
แบ่งเป็น จตุสดมภ์ ๔ กรม ได้แก่ กรมเวียง กรมวัง กรมคลัง และกรมนา
แบ่งเป็น เมืองลูกหลวง (หน้าด่าน ๔ ทิศ: ลพบุรี นครนายก พระประแดง สุพรรณบุรี) เมืองพระยามหานคร และประเทศราช
๒. อยุธยาตอนกลาง
(สมัยพระบรมไตรโลกนาถ)
แยกฝ่ายทหาร (สมุหพระกลาโหม) และฝ่ายพลเรือน (สมุหนายก) กำกับจตุสดมภ์ (นครบาล ธรรมาธิกรณ์ โกษาธิบดี เกษตราธิการ)
ยกเลิกเมืองลูกหลวง จัดเป็น หัวเมืองชั้นใน (ผู้รั้ง) หัวเมืองชั้นนอก (เมืองเอก โท ตรี จัตวา) และเมืองประเทศราช
๓. อยุธยาตอนปลาย
(พ.ศ. ๒๒๓๑ – ๒๓๑๐)
ถ่วงดุลอำนาจโดยแบ่งพื้นที่บังคับบัญชาทั้งทหารและพลเรือน: ๑) สมุหนายก ดูแลหัวเมืองฝ่ายเหนือ ๒) สมุหพระกลาโหม ดูแลหัวเมืองฝ่ายใต้ และ ๓) โกษาธิบดี (พระคลัง) ดูแลหัวเมืองชายทะเลตะวันออก
ตอนที่ ๓ : เศรษฐกิจการค้าสำเภา ภาษีอากร และระบบไพร่สมัยอยุธยา (๖ คะแนน)
.......... ๑. พระคลังสินค้า [ ค ]
.......... ๒. จังกอบ [ ก ]
.......... ๓. อากร [ ฉ ]
.......... ๔. ส่วย [ ข ]
.......... ๕. ฤชา [ ง ]
.......... ๖. การเข้าเดือนออกเดือน [ จ ]
ก. ภาษีเก็บตามด่านขนอนโดยวัดความกว้างปากเรือ
ข. สิ่งของหรือแร่ธาตุที่ส่งแทนการถูกเกณฑ์แรงงาน
ค. หน่วยงานผูกขาดการซื้อขายสินค้าต้องห้ามของรัฐ
ง. ค่าธรรมเนียมที่รัฐเรียกเก็บจากการติดต่อราชการ/ศาล
จ. หน้าที่ของไพร่ในการถูกเกณฑ์แรงงานปีละ ๖ เดือน
ฉ. ภาษีเก็บจากการประกอบอาชีพ เช่น ค่านา สุรา บ่อนเบี้ย

ใบงานที่ ๒.๒ เรื่อง ความสัมพันธ์กับต่างประเทศ ภูมิปัญญา และการเสียกรุงศรีอยุธยา

วิชาประวัติศาสตร์ ม.๒ (พว.) ฉบับเฉลยครู
ชื่อ-นามสกุล: ............................................................................................ ชั้น: ม.๒ / ......... เลขที่: ......... คะแนนที่ได้: ........ / ๒๐ คะแนน
ตอนที่ ๑ : สรุปผังความคิด (Mind Mapping) ความสัมพันธ์ต่างชาติและภูมิปัญญาสมัยอยุธยา (๑๒ คะแนน)
✨ ความสัมพันธ์กับต่างชาติและภูมิปัญญาสมัยอยุธยา
๑. ความสัมพันธ์กับประเทศในเอเชีย(๓ คะแนน)
• จีน: ค้าขายในระบบ บรรณาการ (จิ้มก้อง)
• ญี่ปุ่น: สินค้าที่ญี่ปุ่นต้องการซื้อคือ หนังกวาง, ไม้ฝาง
  หัวหน้ากรมอาสาญี่ปุ่นคือ: ออกญาเสนาภิมุข (ยามาดะ)
๒. ความสัมพันธ์กับชาติตะวันตก(๓ คะแนน)
• ชาติตะวันตกชาติแรก (พ.ศ. ๒๐๕๔): โปรตุเกส (นำปืนไฟเข้ามา)
• สมัยสมเด็จพระนารายณ์มหาราช: ดึงชาติ ฝรั่งเศส
  มาถ่วงดุลอำนาจกับชาติ ฮอลันดา (ดัตช์)
  ราชทูตไทยที่ไปฝรั่งเศสคือ: เจ้าพระยาโกษาธิบดี (ปาน)
๓. ภูมิปัญญาด้านสถาปัตยกรรม-ศิลปะ(๓ คะแนน)
• วัดในเขตพระราชวังหลวง (เจดีย์ทรงลังกา ๓ องค์):
  คือวัด วัดพระศรีสรรเพชญ์
• วัดพระปรางค์สมัยพระเจ้าปราสาททอง: วัดไชยวัฒนาราม
• พระพุทธรูปเอกลักษณ์อยุธยาตอนปลาย: พระพุทธรูปทรงเครื่อง
๔. ภูมิปัญญาด้านภาษาและวรรณกรรม(๓ คะแนน)
• แบบเรียนภาษาไทยเล่มแรก: เรื่อง จินดามณี
  ผู้แต่งคือ: พระโหราธิบดี (สมัยพระนารายณ์ฯ)
• วรรณกรรมพิธีถือน้ำพิพัฒน์สัตยา: ลิลิตโองการแช่งน้ำ
• ผู้แต่งกาพย์เห่เรือ: เจ้าฟ้าธรรมธิเบศร (เจ้าฟ้ากุ้ง)
ตอนที่ ๒ : เปรียบเทียบการเสียกรุงศรีอยุธยา ครั้งที่ ๑ (พ.ศ. ๒๑๑๒) และ ครั้งที่ ๒ (พ.ศ. ๒๓๑๐) (๘ คะแนน)
ประเด็นวิเคราะห์ การเสียกรุงศรีอยุธยา ครั้งที่ ๑ (พ.ศ. ๒๑๑๒) การเสียกรุงศรีอยุธยา ครั้งที่ ๒ (พ.ศ. ๒๓๑๐)
๑. สาเหตุสำคัญของความพ่ายแพ้
ความแตกแยกระหว่างราชสำนักอยุธยากับหัวเมืองฝ่ายเหนือ (เมืองพิษณุโลก) และกองทัพพระเจ้าบุเรงนองมีความเข้มแข็งมาก
การแย่งชิงราชสมบัติในราชวงศ์บ้านพลูหลวงทำให้เสียขุนนางคนสำคัญ การระดมพลไพร่ล้มเหลว และพม่าล้อมกรุงข้ามฤดูน้ำหลาก
๒. ผลกระทบและผู้กอบกู้เอกราช
ตกเป็นประเทศราชพม่า ๑๕ ปี บ้านเมืองไม่ถูกเผาทำลาย / ผู้กอบกู้เอกราชคือ สมเด็จพระนเรศวรมหาราช (พ.ศ. ๒๑๒๗)
บ้านเมืองถูกเผาทำลายจนอยุธยาล่มสลายถาวร / ผู้กอบกู้เอกราชใน ๗ เดือนคือ สมเด็จพระเจ้าตากสินมหาราช (พ.ศ. ๒๓๑๐)
