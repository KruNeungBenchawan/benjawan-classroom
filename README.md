# ห้องเรียนครูเบ็ญจวรรณ (Chibi Edition)

เว็บไซต์รวบรวมสื่อการสอน ใบงาน แผนการจัดการเรียนรู้ และเอกสารต่างๆ อย่างเป็นหมวดหมู่ ในธีมการ์ตูน Chibi สุดน่ารัก

## ฟีเจอร์หลัก
- **หน้าโปรไฟล์ครูเบ็ญจวรรณ & กระดานประกาศข่าวสาร** พร้อมภาพประกอบการ์ตูน Chibi
- **แบ่งหมวดหมู่ชัดเจน** (แผนการสอน, ใบงาน / แบบฝึกหัด, สื่อการสอน / วิดีโอ, ข้อสอบ / แบบประเมิน, เอกสารทั่วไป / แบบฟอร์ม)
- **ค้นหาและกรองข้อมูลรวดเร็ว** ตามคำค้นหา รายวิชา ระดับชั้น และเรียงลำดับ
- **โหมดครูผู้สอน** สำหรับเพิ่ม/แก้ไข/ลบสื่อและประกาศ รวมถึงสำรอง/นำเข้าข้อมูลเป็นไฟล์ `.json`

## ไฟล์ในโปรเจกต์
- `index.html` — หน้าเว็บไซต์หลัก
- `styles.css` — สไตล์ธีมการ์ตูน Chibi
- `data.js` — ข้อมูลเริ่มต้นของห้องเรียน
- `app.js` — ระบบจัดการข้อมูลและการแสดงผล
- `assets/chibi-teacher.jpg` — ภาพประกอบการ์ตูน Chibi ครูเบ็ญจวรรณ
