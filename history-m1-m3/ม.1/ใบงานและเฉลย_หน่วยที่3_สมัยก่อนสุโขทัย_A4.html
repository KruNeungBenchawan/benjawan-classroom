วิชาประวัติศาสตร์ ม.๑ (พว.) ฉบับเฉลยครู
ชื่อ-นามสกุล: ............................................................................................ ชั้น: ม.๑ / ......... เลขที่: ......... คะแนนที่ได้: ........ / ๒๐ คะแนน
ตอนที่ ๑ : เติมข้อมูลเปรียบเทียบพัฒนาการของมนุษย์สมัยก่อนประวัติศาสตร์ในดินแดนไทย (๑๐ คะแนน)
ยุคสมัย ลักษณะเครื่องมือเครื่องใช้สำคัญ วิถีการดำรงชีวิต / สังคม ตัวอย่างแหล่งโบราณคดีในไทย
๑. ยุคหินเก่า
(๗๐๐,๐๐๐ - ๑๐,๐๐๐ ปีมาแล้ว)
เครื่องมือหินกรวดกะเทาะแบบหยาบๆ (กะเทาะหน้าเดียว) ใช้ทุบ สับ ขุด
เร่ร่อน ล่าสัตว์ เก็บหาของป่า อาศัยตามถ้ำและเพิงผา
ถ้ำพระ อ.ไทรโยค จ.กาญจนบุรี, บ้านแม่ทะ จ.ลำปาง
๒. ยุคหินกลาง
(๑๐,๐๐๐ - ๔,๐๐๐ ปีมาแล้ว)
เครื่องมือหินกะเทาะที่ประณีตขึ้น ขนาดเล็กลง (วัฒนธรรมโฮบินเนียน)
อาศัยในถ้ำ/เพิงผาใกล้แหล่งน้ำ เริ่มอยู่กึ่งตั้งหลักแหล่งและรู้จักสะสมเมล็ดพืช
ถ้ำผีแมน จ.แม่ฮ่องสอน, ถ้ำเขาทะลุ จ.กาญจนบุรี
๓. ยุคหินใหม่
(๔,๐๐๐ - ๒,๕๐๐ ปีมาแล้ว)
ขวานหินขัด (ผิวเรียบ มีคม) และภาชนะดินเผา (เช่น หม้อสามขา)
ตั้งหลักแหล่งถาวรเป็นหมู่บ้านริมน้ำ ทำการเพาะปลูกและเลี้ยงสัตว์ ทอผ้า
แหล่งโบราณคดีบ้านเก่า จ.กาญจนบุรี, โคกพนมดี จ.ชลบุรี
๔. ยุคสำริด
(๒,๕๐๐ - ๑,๕๐๐ ปีมาแล้ว)
เครื่องมือโลหะสำริด (ทองแดงผสมดีบุก) และภาชนะดินเผาลายเขียนสี
ชุมชนเกษตรกรรมขนาดใหญ่ มีพิธีกรรมฝังศพพร้อมสิ่งของเครื่องใช้
แหล่งโบราณคดีบ้านเชียง จ.อุดรธานี (มรดกโลก), บ้านโนนวัด
๕. ยุคเหล็ก
(๒,๕๐๐ - ๑,๕๐๐ ปีมาแล้ว)
เครื่องมือและอาวุธเหล็กที่มีความแข็งแกร่งทนทานสูง
ขยายพื้นที่เกษตรกรรม มีคูน้ำคันดิน มีชนชั้นผู้นำ ติดต่อค้าขายกับต่างชาติ
แหล่งโบราณคดีบ้านดอนตาเพชร จ.กาญจนบุรี, เนินอุโลก
ตอนที่ ๒ : นำตัวอักษรหน้าหลักฐานทางโบราณคดี (ก – จ) มาเติมหน้าแหล่งโบราณคดีที่สัมพันธ์กัน (๕ คะแนน)
.......... ๑. แหล่งโบราณคดีบ้านเชียง (จ.อุดรธานี) [ ข ]
.......... ๒. แหล่งโบราณคดีบ้านเก่า (จ.กาญจนบุรี) [ ก ]
.......... ๓. แหล่งโบราณคดีบ้านดอนตาเพชร (จ.กาญจนบุรี) [ ง ]
.......... ๔. อุทยานแห่งชาติผาแต้ม (จ.อุบลราชธานี) [ ค ]
.......... ๕. แหล่งโบราณคดีถ้ำผีแมน (จ.แม่ฮ่องสอน) [ จ ]
ก. พบภาชนะดินเผา "หม้อสามขา" และขวานหินขัดยุคหินใหม่
ข. มรดกโลกที่โดดเด่นด้วยภาชนะดินเผาลายเขียนสีและสำริด
ค. ภาพเขียนสีสมัยก่อนประวัติศาสตร์บนผนังหน้าผาริมแม่น้ำโขง
ง. ชุมชนยุคเหล็กที่พบลูกปัดหินคาร์เนเลียนและสำริดติดต่อกับอินเดีย
จ. พบเมล็ดพืชโบราณและโลงไม้ขุดบนเพิงผาสูงในภาคเหนือ
ตอนที่ ๓ : วิเคราะห์หลักฐานทางประวัติศาสตร์ (Active Learning) (๕ คะแนน)

สถานการณ์ศึกษา: นักโบราณคดีขุดค้นพบ "โครงกระดูกมนุษย์ที่ถูกฝังร่วมกับภาชนะดินเผาบรรจุอาหาร กำไลสำริด และเครื่องมือเหล็ก รวมถึงพบลูกปัดแก้วและลูกปัดหินมีค่าที่ผลิตจากประเทศอินเดีย"

๑. หลักฐานข้างต้นสะท้อนให้เห็นความเชื่อและวิถีเศรษฐกิจของคนในชุมชนโบราณนี้อย่างไรบ้าง? (๓ คะแนน)

๑) ด้านความเชื่อ: มีความเชื่อเรื่องชีวิตหลังความตาย จึงฝังอาหารและเครื่องประดับไปพร้อมกับผู้ตาย และสะท้อนฐานะทางสังคม
๒) ด้านเศรษฐกิจ: นอกจากการเกษตรแล้ว ยังมีการติดต่อค้าขายแลกเปลี่ยนสินค้าระยะไกลกับพ่อค้าต่างชาติ (อินเดีย)

๒. เพราะเหตุใดการเปลี่ยนมาใช้ "เครื่องมือเหล็ก" จึงช่วยให้ชุมชนโบราณพัฒนาไปเป็น "เมืองและรัฐโบราณ" ได้เร็วขึ้น? (๒ คะแนน)

เพราะเหล็กมีความแข็งแกร่งทนทานกว่าหินและสำริดมาก ทำให้ถางป่าขยายพื้นที่ทำนาได้ผลผลิตอาหารจำนวนมาก รองรับประชากรที่เพิ่มขึ้น และใช้อาวุธเหล็กป้องกันหรือขยายอำนาจของเมือง

ตอนที่ ๑ : สรุปผังความคิด (Mind Mapping) รัฐโบราณในดินแดนไทย ๔ ภูมิภาค (๑๒ คะแนน)
🏛️ รัฐโบราณในดินแดนไทยก่อนสมัยสุโขทัย
๑. ภาคกลาง(๓ คะแนน)
• อาณาจักรทวารวดี: ศูนย์กลางที่ จ.นครปฐม / ลุ่มน้ำเจ้าพระยา
  ศาสนาหลัก: พระพุทธศาสนาเถรวาท
  หลักฐานสำคัญ: ธรรมจักรศิลาและกวางหมอบ
• แคว้นละโว้: ศูนย์กลางที่ จ.ลพบุรี
  โบราณสถานสำคัญ: พระปรางค์สามยอด / ศาลพระกาฬ
๒. ภาคเหนือ(๓ คะแนน)
• แคว้นหริภุญชัย: ศูนย์กลางที่ จ.ลำพูน
  ปฐมกษัตริย์: พระนางจามเทวี (จากเมืองละโว้)
  หลักฐานสำคัญ: พระธาตุหริภุญชัย, เจดีย์กู่กุด
• แคว้นโยนกนาคนคร / เงินยาง: ตั้งอยู่ที่ จ.เชียงราย
  ต่อมารวมเป็นอาณาจักร: ล้านนา (โดยพญามังราย)
๓. ภาคตะวันออกเฉียงเหนือ (อีสาน)(๓ คะแนน)
• แคว้นศรีโคตรบูร: ตั้งอยู่บริเวณ สองฝั่งแม่น้ำโขง (นครพนม)
  ศาสนสถานคู่บ้านคู่เมือง: พระธาตุพนม จ.นครพนม
• ชุมชนวัฒนธรรมขอมโบราณ (อีสานใต้):
  บริเวณลุ่มน้ำ: แม่น้ำมูล - แม่น้ำชี
  ปราสาทหินสำคัญ: ปราสาทหินพิมาย, ปราสาทพนมรุ้ง
๔. ภาคใต้(๓ คะแนน)
• แคว้นลังกาสุกะ: ศูนย์กลางที่ เมืองโบราณยะรัง จ.ปัตตานี
• อาณาจักรศรีวิชัย: ศูนย์กลางที่ อ.ไชยา จ.สุราษฎร์ธานี
  นับถือศาสนา: พระพุทธศาสนานิกายมหายาน
• แคว้นตามพรลิงค์: ศูนย์กลางที่ จ.นครศรีธรรมราช
  เผยแผ่พุทธศาสนาลัทธิ: เถรวาท ลัทธิลังกาวงศ์
ตอนที่ ๒ : ระบุชื่อ "รัฐโบราณ" จากหลักฐานและข้อมูลทางประวัติศาสตร์ที่กำหนดให้ (๕ คะแนน)
ข้อมูลและหลักฐานทางประวัติศาสตร์ ชื่อรัฐ / แคว้นโบราณ
๑. พบเหรียญเงินจารึกภาษาสันสกฤตว่า "ศรีทวารวดีศวรปุณยะ" และบันทึกพระภิกษุจีนเหี้ยนจังเรียกว่า "โถโลโปตี้" อาณาจักรทวารวดี
๒. พบประติมากรรม "พระโพธิสัตว์อวโลกิเตศวรสำริด" และ "พระบรมธาตุไชยา" รุ่งเรืองด้วยพุทธศาสนามหายานและการค้าทางทะเล อาณาจักรศรีวิชัย
๓. ฤๅษีวาสุเทพสร้างเมืองและอัญเชิญ "พระนางจามเทวี" จากเมืองละโว้มาเป็นปฐมกษัตริย์ มีโบราณสถานคือเจดีย์กู่กุด แคว้นหริภุญชัย
๔. เมืองท่าสำคัญทางภาคใต้ที่เป็นศูนย์กลางของ "พระพุทธศาสนาเถรวาท ลัทธิลังกาวงศ์" และมีพระบรมธาตุเจดีย์ไร้เงา แคว้นตามพรลิงค์ (นครศรีธรรมราช)
๕. เมืองสำคัญลุ่มน้ำลพบุรี-ป่าสัก ที่รับอิทธิพลศิลปะขอมโบราณ มีโบราณสถานสำคัญคือ "พระปรางค์สามยอด" และเคยส่งทูตไปจีนในชื่อ "หลอฮก" แคว้นละโว้ (ลพบุรี)
ตอนที่ ๓ : คำถามคิดวิเคราะห์และเชื่อมโยงประวัติศาสตร์ (๓ คะแนน)

คำถาม: ปัจจัยใดบ้างที่ทำให้ชุมชนโบราณในดินแดนไทยสามารถพัฒนาขึ้นเป็น "รัฐโบราณ" ที่มีความเจริญรุ่งเรือง และรัฐโบราณเหล่านี้วางรากฐานให้แก่อาณาจักรสุโขทัยอย่างไร?

๑) ปัจจัยความเจริญ: มีที่ตั้งทางภูมิศาสตร์ที่อุดมสมบูรณ์ริมแม่น้ำและชายฝั่งทะเล (สุวรรณภูมิ) เป็นจุดแวะพักการค้าทางทะเลระหว่างอินเดียกับจีน
๒) การวางรากฐานสู่สุโขทัย: รัฐโบราณได้传ทอดพระพุทธศาสนา (โดยเฉพาะลังกาวงศ์จากนครศรีธรรมราช) รูปแบบอักษร ศิลปกรรม และระบบการปกครองให้แก่สุโขทัย
